# බෝට්ටු කරවල වෙළඳසැල — Shop Management System

Responsive web app foundation for the Boat Fish Shop at වැලිකඩ, අධිකාරිගම.

## Current foundation
- Responsive desktop and mobile layout
- KING (blue) and QUEEN (green) identity selection
- Dashboard overview and quick-action shortcuts
- Navigation shell for all planned business modules
- Initial PWA manifest

## Important status
This is a UI foundation only. The current KING / QUEEN selection is a prototype identity switch, **not secure authentication**. Dashboard figures are placeholders; no sales, stock, debt, or payment data is stored yet.

## Planned development
1. Secure KING and QUEEN sign-in with equal permissions
2. Cloud database, shared live data, and audit history
3. Purchases, batch-based inventory, COD allocation, and FIFO costing
4. POS sales, customer and supplier ledgers, and thermal invoices
5. Income, expenses, profit reports, backups, and settings

## Run locally
Open `index.html` in a modern browser. For PWA testing, serve this folder over HTTPS or localhost.

## Tech
Vanilla HTML, CSS, and JavaScript.
